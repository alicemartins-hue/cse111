# 📘 CSE111 – Programming with Functions
## 🍂 Fall 2025

My repository for **BYU–Idaho / BYU Pathway Worldwide CSE111** class projects.  
This course focuses on **Python programming fundamentals**, problem-solving, and writing clean, reusable code using functions.

⚠️ This repository is for personal study purposes only.  
It is not intended to encourage plagiarism or misuse of course materials.

---

## 📂 Projects Overview

The repository is organized by weeks, following the structure of the course.

### 🧩 sample
Contains example or starter files used to understand basic concepts and program structure.

---

### 📅 week1
Introduction to Python basics:
- Variables
- Input and output
- Simple calculations and expressions

---

### 📅 week2
Conditional logic and decision-making:
- `if`, `elif`, and `else`
- Boolean expressions
- Basic program flow control

---

### 📅 week3
Repetition and loops:
- `while` loops
- `for` loops
- Loop control and counters

---

### 📅 week4
Functions and code reuse:
- Defining and calling functions
- Parameters and return values
- Improving readability and structure

---

### 📅 week5
Data collections:
- Lists
- Iteration over collections
- Basic data manipulation

---

### 📅 week6–week7
More advanced programs that combine multiple concepts learned throughout the course, focusing on:
- Problem decomposition
- Function-based design
- Clean and maintainable code

---

### 📄 Additional Files

- **pil.py** – A Python script developed during the course.
- **cse111_reflection.docx** – Personal reflection on the learning experience in CSE111.
